# MAMRYA

온마음 & 김리안 페어 소개 사이트입니다.

---

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 이름은 `onmaeum-rian.github.io` 처럼 지으면 주소가 깔끔합니다.
2. 이 폴더 안의 파일을 **폴더째가 아니라 안에 든 것들만** 통째로 업로드합니다.
   (`index.html` 이 저장소 맨 바깥에 있어야 합니다)
3. 저장소 → Settings → Pages → Branch를 `main` / `/(root)` 으로 두고 저장합니다.
4. 1~2분 뒤 주소로 들어가면 사이트가 뜹니다.

---

## 2. 내용 바꾸기

**`assets/js/data.js` 파일 하나만 고치면 됩니다.**

파일을 열면 항목마다 설명이 달려 있습니다. 따옴표 `' '` 안의 글자만 바꾸고,
쉼표와 괄호는 그대로 두세요.

바꿀 수 있는 것

| 항목 | 내용 |
|---|---|
| `site` | 작품명, 공연장, 주소창 글자, 배경 사진, 자컾 사진 |
| `info` | 정보창에 뜨는 항목들 (원하는 만큼 추가·삭제) |
| `since` | 사귄 날. D+숫자와 N년차가 자동 계산됩니다 |
| `anniversaries` | 다가오는 날짜. D-숫자가 자동 계산됩니다 |
| `ticket` | 대문 티켓에 적히는 내용 |
| `banners` | 홈 배너. 두 개 이상이면 화살표가 생깁니다 |
| `shows` | 공연 중 포스터 목록 |
| `numbers` | 넘버(노래) 목록 |
| `cast` | 두 사람의 이름, 배역, 사진, 프로필 링크 |
| `days` | 캘린더에 넣을 사진과 설명 |
| `booking` | 예매 날짜, 회차, 좌석표 |
| `links` | 트위터·티스토리 등 바깥 링크 |
| `dialogues` | 대화창에 뜨는 대화 세트 (무작위) |
| `replies` | 말을 걸었을 때의 답 |
| `notice` | 알림 주기와 알림 대사 |

## 3. 사진 넣기

`assets/img/` 폴더에 사진을 올린 뒤, `data.js`에 경로를 적습니다.

```
image: 'assets/img/0418.jpg'
```

넣을 자리

- 배경: `site.background`
- 배경 동영상: `site.backgroundVideo` (mp4를 `assets/video/` 에 올린 뒤 경로 적기.
  소리 없이 자동 반복되며, 넣으면 배경 사진 대신 재생됩니다)
- 자컾 사진(정보창): `site.poster`
- 캐스트 사진: `cast` 안의 `image`
- 포스터: `shows` 안의 `image`
- 캘린더 사진: `days` 안의 `image`

경로를 비워두면(`''`) 색 배경만 나옵니다.

## 4. 노래 넣기

`assets/music/` 폴더에 mp3를 올리고 `data.js`에 경로를 적습니다.

```
{ title: '개강 첫날', length: '3:24', file: 'assets/music/01.mp3' }
```

**입장하기 버튼을 누르는 순간 첫 곡이 재생됩니다.**
브라우저는 클릭 없이 소리를 내는 걸 막기 때문에, 이 방식이라야 소리가 납니다.

왼쪽 아래 ♪ 버튼을 누르면 재생 창이 열리고, 재생·정지·곡 넘기기를 할 수 있습니다.

> 저작권이 있는 곡은 올리지 마세요. 직접 만들었거나 커미션 받은 곡, 자유 이용 음원만 올리세요.

## 5. 대화와 알림

- 사이트에 들어오면 `dialogues` 중 한 세트가 무작위로 대화창에 들어갑니다.
- 입력창에 말을 걸면 `replies`의 키워드에 맞는 답이 나옵니다. 없으면 `fallback`이 나옵니다.
- `notice.everyMinutes` 마다 `notice.lines` 중 하나가 알림처럼 떴다가 사라집니다.
  기본은 5분이고, 알림을 누르면 대화창이 열립니다.

---

## 6. 색 바꾸기

`assets/css/style.css` 맨 위 `:root` 안의 색만 바꾸면 사이트 전체 색이 바뀝니다.
글자 크기는 같은 곳의 `--fz` 값을 줄이면 전체가 작아집니다.

---

## 7. 알아둘 것

- 서버가 없는 사이트라, 방문자가 대화창에 쓴 말은 저장되지 않습니다. 새로고침하면 사라집니다.
- PC와 모바일 화면이 자동으로 바뀝니다. 모바일에서는 정보창이 맨 위 서랍으로 올라가고,
  아래 가운데에 이동 버튼이, 왼쪽에 음악, 오른쪽에 대화 버튼이 놓입니다.

## 8. 관리자 페이지

주소 뒤에 `/admin.html` 을 붙이면 관리자 페이지가 열립니다.

```
아이디.github.io/MAMRYA/admin.html
```

여기서 모든 내용을 화면에서 고칠 수 있습니다. 다 고친 뒤 아래 **data.js 내려받기**
를 누르면 파일이 하나 받아집니다. 그 파일을 GitHub의 `assets/js` 폴더에
덮어쓰면 사이트에 반영됩니다.

- 항목마다 **+ 추가** 와 **삭제** 버튼이 있어 개수를 늘리고 줄일 수 있습니다.
- 사진과 음악은 파일을 먼저 GitHub에 올린 뒤, 경로만 적으면 됩니다.
- **지금 사이트 내용 불러오기** 를 누르면 고치던 걸 버리고 처음 상태로 돌아갑니다.
- **미리보기** 를 누르면 고친 내용이 실제 사이트 화면으로 바로 보입니다.
  PC / 모바일 버튼으로 두 화면을 번갈아 볼 수 있습니다.
  (미리보기는 GitHub에 올린 주소로 열었을 때만 됩니다. 컴퓨터에서 파일을
  직접 연 경우에는 브라우저 제한으로 동작하지 않습니다.)

> 관리자 페이지는 비밀번호가 없습니다. 주소를 아는 사람은 열어볼 수 있지만,
> 거기서 고친다고 사이트가 바뀌지는 않습니다. 실제 반영은 GitHub에 파일을
> 덮어써야만 되기 때문입니다.
